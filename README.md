# Sidnei Costa — site institucional

Site estático, responsivo e pronto para edição no VS Code.

## Visualizar localmente

Abra a pasta no VS Code e use uma extensão como **Live Server**, ou execute:

```powershell
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
